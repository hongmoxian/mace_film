# Magnetic-reversal symmetry example

This optional example demonstrates global magnetic-reversal symmetry
using a separately trained model.pt and a sample structure.

~~~bash
python tests/validate_trained_symmetry.py
~~~

Run this command from the repository root with the required dependencies
installed. See docs/MAGNETIC_SYMMETRY.md for the theory and model usage.

The symmetry-mode checkpoint is not interchangeable with the
standard MD/PES demonstration checkpoints.
